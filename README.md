# NEON STRIKE — بستهٔ آمادهٔ استقرار روی Render

این ZIP عمداً فایل‌ها را در ریشه قرار می‌دهد؛ پس از استخراج، `package.json` و `server.js` باید مستقیماً در پوشهٔ اصلی دیده شوند.

## استقرار روی Render

1. ZIP را دانلود و استخراج کن.
2. تمام محتویات همین پوشه (نه خود پوشهٔ بیرونی) را در ریشهٔ یک مخزن GitHub آپلود کن؛ ساختار باید شبیه این باشد:

```text
package.json
server.js
README.md
public/
  index.html
```

3. در Render گزینهٔ **New + → Web Service** را بزن و مخزن GitHub را وصل کن.
4. تنظیمات سرویس:
   - **Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Health Check Path (اگر نمایش داده شد):** `/healthz`
5. Deploy را اجرا کن. پس از اتمام، آدرس `https://....onrender.com` را باز کن.

## ساخت اتاق و ورود با کد

1. هر دو بازیکن همان آدرس Render را باز کنند.
2. از «حالت بازی» گزینهٔ «آنلاین — همه علیه همه» را انتخاب کنند.
3. بازیکن اول «ساخت اتاق خصوصی» را بزند؛ کد پنج‌حرفی در کادر «کد اتاق» ظاهر می‌شود. دکمهٔ «کپی کد اتاق» کد را برای ارسال کپی می‌کند.
4. بازیکن دوم کد را در همان کادر وارد کند و «ورود با کد» را بزند.
5. هر بازیکن بعد از مشاهدهٔ پیام پیوستن به اتاق، «ورود به میدان» را بزند. ظرفیت اتاق حداکثر ۸ نفر است.

## اجرای محلی (اختیاری)

Node.js 20 یا جدیدتر نصب باشد، سپس در پوشهٔ پروژه اجرا کن:

```bash
npm install
npm start
```

مرورگر: `http://localhost:10000`

## محدودیت‌ها

این یک نمونهٔ اولیهٔ آنلاین است و نه نسخهٔ نهایی رقابتی. اتاق‌ها فقط تا زمان روشن‌بودن همان نمونهٔ سرور در حافظه هستند؛ با راه‌اندازی مجدد پاک می‌شوند. سیستم حساب کاربری، ضدتقلب قوی، بازیابی خودکار بازیکن پس از قطع اتصال و آزمون بار کامل ندارد. برای بازی به اینترنت نیاز است چون Three.js از CDN بارگیری می‌شود.

## اگر Render خطای Dockerfile می‌دهد
این پروژه اکنون فایل `Dockerfile` هم دارد. در Render، مخزن را دوباره Deploy کن و مطمئن شو Root Directory خالی است (یا پوشه‌ای است که `Dockerfile` و `package.json` در آن قرار دارند). اگر نوع سرویس روی Docker تنظیم شده، Render باید همین `Dockerfile` را از ریشهٔ مخزن پیدا کند. فایل‌های پروژه را داخل یک پوشهٔ اضافی قرار نده؛ `Dockerfile` باید در ریشهٔ مخزن باشد.

اگر می‌خواهی به‌جای Docker از محیط Node استفاده کنی، سرویس جدید از نوع Node Web Service بساز و Build Command را `npm install` و Start Command را `npm start` قرار بده.
